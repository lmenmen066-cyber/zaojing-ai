## 🐛 问题根因

### 旧代码错误

```python
# packages/agent-service/src/zaojing/services/license_service.py (OLD)

def _machine_id():
    user = platform.uname().username or "user"  # ❌ AttributeError!
    ...
```

**错误信息**:
```
AttributeError: 'uname_result' object has no attribute 'username'
File: license_service.py, line 49, in _machine_id
```

### 技术细节

`platform.uname()` 返回的是 `uname_result` 对象，其字段为:
- `system`
- `node`
- `release`
- `version`
- `machine`
- `processor`

**没有 `username` 字段!**

## ✅ 修复方案

### 1. 核心修复 - `_machine_id()` 重写

```python
# NEW IMPLEMENTATION

import hashlib
import getpass
import logging
import os
import platform
import uuid

logger = logging.getLogger(__name__)


def _safe_getuser() -> str:
    """安全获取用户名，多源 fallback"""
    try:
        user = getpass.getuser()
        if user:
            return user
    except Exception as e:
        logger.warning("getpass.getuser() failed", exc_info=True)

    return (
        os.environ.get("USERNAME")
        or os.environ.get("USER")
        or os.environ.get("LOGNAME")
        or "user"
    )


def _safe_node() -> str:
    """安全获取主机名"""
    try:
        node = platform.node()
        if node:
            return node
    except Exception as e:
        logger.warning("platform.node() failed", exc_info=True)
    return "unknown-node"


def _safe_mac() -> str:
    """安全获取 MAC 地址"""
    try:
        return str(uuid.getnode())
    except Exception as e:
        logger.warning("uuid.getnode() failed", exc_info=True)
        return "0"


def _machine_id() -> str:
    """
    生成稳定机器码 (SHA-256 哈希)
    
    修复要点:
    - 不再使用 platform.uname().username
    - 任何子项失败都不能抛异常
    - 输出 SHA-256，避免泄露原始主机信息
    """
    parts = [
        platform.system() or "unknown-os",
        platform.machine() or "unknown-arch",
        _safe_node(),
        _safe_mac(),
        _safe_getuser(),
    ]
    raw = "|".join(parts)
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()
```

### 2. LicenseManager 降级启动

```python
class LicenseManager:
    def __init__(self):
        self.degraded = False
        self.degraded_reason = None
        self.machine_id = "unknown-machine"
        
        try:
            self.machine_id = _machine_id()
            logger.info(f"Machine ID generated: {self.machine_id[:16]}...")
        except Exception as e:
            logger.exception("machine_id generation failed")
            self.machine_id = "unknown-machine"
            self.degraded = True
            self.degraded_reason = "machine_id_unavailable"
            logger.critical("License service running in degraded mode")
```
